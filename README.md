## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and directory **/(root)**, then click **Save**.
4. Open all three URLs above and verify they work without GitHub login.
5. Check the policy text against the actual implementation, and only then enter the URLs in Google Cloud Console → Google Auth Platform → Branding.

GitHub Pages URLs are free, but Google may require verification of a domain you control for some OAuth publishing/verification paths; acceptance of a shared github.io host is not guaranteed.

The NES0_CORE recovery environment is out of scope.
