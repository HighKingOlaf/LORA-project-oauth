Personal-use utility · Google Drive integration

Encrypted backups for a personal project memory system.

LORA.Project is a privately operated software utility that uses Google Drive to store encrypted backup copies of the operator's project-memory archives. It is not a public file-sharing platform or a hosted AI service.

Local encryption

Project files are encrypted on the operator's computer before backup files are uploaded to Google Drive.

Google Drive storage

With the owner's authorization, the utility creates, retrieves and verifies backup objects within the files it is permitted to use.

Recovery checks

Downloaded encrypted copies can be decrypted locally and checked for integrity as part of the recovery workflow.

How it uses Google permissions

LORA.Project uses the Google Drive API with the drive.file scope, granting access to files created by or explicitly opened with the application. The utility uses this permission for its encrypted backup and restore operations, not to index the owner's entire Google Drive.

Private by design: This informational website does not provide access to private files or authenticate users. It contains no API keys, memory archives, or OAuth credentials.

Transparency and support

Read our privacy policy for the handling of Google user data and our terms of service for intended use. For questions about the application, use the project’s public issue tracker. Do not include passwords, tokens, or personal records in issues.
