Privacy policy

This policy describes how LORA.Project, a privately operated personal backup utility, handles Google user data when authorized by its operator.

1. Operator and purpose

LORA.Project is a personal-use tool maintained by the GitHub account HighKingOlaf. It stores and verifies encrypted backups of a personal project-memory archive in Google Drive. This website is informational; it does not log in to Google, take uploads, or handle backup content.

2. Google data accessed

With explicit Google authorization, LORA.Project uses the Google Drive API drive.file scope to access Drive files created by the application or files the operator explicitly makes available to it. In this workflow, that includes encrypted backup objects and necessary metadata (such as file names, file IDs, sizes, and timestamps) for upload, listing, verification, download and recovery.

The application does not request general access to all files in Google Drive through broader Drive scopes.

3. How data is used

  • Create or retrieve encrypted project-memory backup objects, as directed by the operator.
  • Check backup integrity and support local recovery testing.
  • Maintain local operational logs containing backup status and limited file metadata.

Google user data is not used for advertising, profiling, or training AI models. The application does not sell Google user data.

4. Storage, encryption, and security

Project-memory contents are intended to be encrypted locally before upload. Google Drive stores the resulting encrypted backup objects; the operator's computer performs decryption for recovery. Google account authorization is handled through OAuth using locally stored rclone credentials. Such credentials must be protected using operating-system access controls and are not intended to be part of cloud backup objects or this website.

Google Drive itself stores and processes the encrypted objects and associated metadata under the operator's Google account. Local restored files, downloaded ciphertext, reports, and OAuth configuration may remain on the operator's computer until the operator removes them. No security measure is guaranteed to eliminate all risk.

5. Sharing and transfers

Data is transferred to Google only as required for the Google Drive backup, verification, and recovery functions. The operator does not disclose Google user data to advertisers, data brokers, or other third parties. Disclosure may occur if legally required or with the operator's express direction. Google processes Drive data under its own terms and privacy policies.

6. Retention and deletion

Encrypted backups remain in the operator's Google Drive account until the operator deletes them or enables a separate retention policy. Local copies and logs may also remain until manually removed. The operator can review and delete backup objects in Google Drive, revoke application access through Google Account settings, and delete locally stored credentials or recovery copies.

7. Limited use

Any information obtained from Google APIs is used only for the functions described in this policy. It is not used for personalized advertising, sold, or provided to unrelated parties. Human access is not part of the normal automated workflow.

8. Website data

The informational site uses static HTML and CSS without embedded analytics scripts, advertising pixels, login forms, or tracking cookies supplied by LORA.Project. Its hosting provider, GitHub Pages, may process standard technical request information according to GitHub's own policies.

9. Updates and contact

If these practices change, this page will be updated with a new effective date. Questions may be submitted through the public project issue tracker. Please do not post sensitive personal information in public issues.
